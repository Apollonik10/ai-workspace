# Modelos de IA

## Modelos Disponíveis

### Mimo
- Modelo padrão do workspace
- Uso geral

### Gemini
- Google AI
- Multimodal

### OpenRouter
- Agregador de modelos
- Acesso a múltiplos provedores

### NVIDIA NIM
- Modelos otimizados para enterprise
- Alta performance

## Uso

Cada agente pode utilizar um modelo diferente. A configuração está em `configs/workspace.json`.
