# AI Workspace

Ambiente de desenvolvimento pessoal focado em IA, automação, agentes autônomos, RAG, MCP e engenharia de software assistida por modelos de linguagem.

## Estrutura

```
ai-workspace/
├── docs/          # Documentação
├── skills/        # Biblioteca de conhecimento
├── agents/        # Agentes especializados
├── loops/         # Automação
├── rag/           # Memória contextual
├── mcp/           # Integrações externas
├── configs/       # Configurações
├── models/        # Modelos de IA
├── projects/      # Projetos
└── workspace-cli/ # CLI
```

## Início Rápido

1. Navegue até a pasta do projeto
2. Consulte `docs/roadmap.md` para status atual
3. Use agents conforme a tarefa
