# RAG - Retrieval Augmented Generation

## Visão Geral

Sistema de memória contextual que permite aos agentes consultarem documentação antes de responder.

## Fontes de Dados

- Docs do projeto
- Workflow
- Roadmap
- Skills
- Código fonte

## Fluxo

```
Query do Agente → Busca Semântica → Documentos Relevantes → Contexto Enriquecido → Resposta
```

## Benefícios

- Menos alucinação
- Mais consistência
- Melhor contexto
- Respostas baseadas em documentação real

## Implementação Futura

- Indexação automática de documentos
- Busca vetorial
- Ranking de relevância
- Cache de consultas
