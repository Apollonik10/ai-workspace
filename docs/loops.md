# Loops de Automação

## Visão Geral

Loops são sequências automatizadas que orquestram agentes para completar tarefas complexas.

## Loops Disponíveis

### Planning Loop
- Analisa requisitos
- Gera plano de execução
- Divide tarefas
- Prioriza entregas

### Review Loop
- Revisa código
- Verifica padrões
- Valida arquitetura
- Gera relatório

### Fix Loop
- Detecta erros
- Corrige bugs
- Corrige erros de build
- Corrige falhas de lint

### Git Loop
- Gerencia branches
- Cria commits
- Cria pull requests
- Versionamento semântico

### Deploy Loop
- Build do projeto
- Deploy automático
- Verificações pós-deploy
- Notificação de resultado

## Fluxo Geral

```
Input → Planning → Development → Review → Fix → Git → Deploy → Output
```

## Uso

Cada loop pode ser acionado individualmente ou encadeado em pipeline completo.
