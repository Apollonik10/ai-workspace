# Deploy Agent

## Responsabilidade
Deploy e publicação de código.

## Skills
- git
- vercel

## Entrada
Código pronto para deploy, configurações.

## Saída
- Deploy concluído
- URL de produção
- Status do deploy
- Logs de build

## Fluxo

1. Verificar pré-requisitos
2. Rodar testes
3. Build do projeto
4. Deploy
5. Verificação pós-deploy
6. Notificação

## Checklist

- [ ] Código revisado
- [ ] Testes passando
- [ ] Build sem erros
- [ ] Variáveis de ambiente configuradas
- [ ] Deploy verificado
- [ ] Rollback planejado
