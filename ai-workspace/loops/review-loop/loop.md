# Review Loop

## Responsabilidade
Orquestrar revisão de código.

## Fluxo

```
Input (Código)
    ↓
Análise de Padrões
    ↓
Validação SOLID
    ↓
Checagem de Segurança
    ↓
Verificação de Performance
    ↓
Output (Relatório)
```

## Agentes Envolvidos
- Reviewer Agent (principal)

## Inputs
- Código para revisar
- Padrões do projeto
- Regras de segurança

## Outputs
- Relatório de revisão
- Lista de problemas
- Sugestões de melhoria
- Score de qualidade

## Trigger
- Pull Request
- Antes de merge
- Request de revisão
