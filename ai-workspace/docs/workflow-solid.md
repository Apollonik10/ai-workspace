# Workflow Full Stack SOLID

## Visão Geral

Workflow padronizado para todas as tarefas de desenvolvimento no AI Workspace. Baseado nos princípios SOLID e adaptado para agentes de IA.

## Fases do Workflow

### 1. Planejamento
- Analisar requisitos
- Identificar dependências
- Gerar plano de execução
- Dividir em subtarefas

### 2. Desenvolvimento
- Seguir padrões do projeto
- Aplicar SOLID
- Usar Skills como referência
- Manter modularidade

### 3. Revisão
- Verificar código contra padrões
- Validar arquitetura
- Checar segurança
- Documentar decisões

### 4. Refatoração
- Eliminar duplicação
- Simplificar lógica
- Melhorar nomes
- Extrair abstrações quando necessário

### 5. Testes
- Testes unitários
- Testes de integração
- Validação manual
- Edge cases

### 6. Deploy
- Build
- Deploy
- Verificações pós-deploy
- Rollback se necessário

## Regras

- Nunca avançar fase sem concluir a anterior
- Cada commit = 1 responsabilidade
- Documentar decisões arquiteturais
- Revisar antes de merge
